# Google AI Pro · macOS / MuMu

[日本語](README.md) · [English](README.en.md) · [出典・配布範囲](ATTRIBUTION.md)

Google Oneの課金オファーを確認する既存スクリプトを、macOSのMuMuPlayer Proで使うための補助ツールと実行ガイドです。環境の確認、オファー一覧の取得、決済画面の表示に対応しています。購入の確定は利用者が端末で行います。

**参考資料と元ファイルの配布元は、[こちらのX投稿（@zhuxufng154415）](https://x.com/zhuxufng154415/status/2123040170132013071)です。** 元スクリプトと埋め込みモジュールは同梱していません。

## AIに任せる

[AI_TASK.md](AI_TASK.md)を、Macのファイルとターミナルを操作できるAIに渡してください。コピー用の依頼文と、環境準備からオファー取得までの作業指示を日英でまとめています。通常は一覧取得まで進め、決済画面は明示的に依頼した場合だけ開きます。購入確定は利用者が行います。

## 準備

- Python 3.12をインストールしたmacOS
- MuMuPlayer ProのAndroid端末（ADBデバッグとroot権限が必要）
- 対象アカウントでログイン済みのGoogle PlayストアとGoogle One
- 利用する権利を確認した元の`ultra0.py`

元ファイルは上記の配布元から自分で用意し、`vendor/ultra0.py`に配置してください。元の関数構成が異なる版には対応できない場合があります。配布元の投稿本文とリンク先は、こちらではアクセス制限により再確認できていません。

```text
google-ai-pro-macos/
├── mac.py
├── vendor/
│   └── ultra0.py  ← 自分で配置（Gitには含まれません）
└── Mac環境セットアップ.command
```

## セットアップ

```bash
git clone https://github.com/myan69/google-ai-pro-macos.git
cd google-ai-pro-macos
# vendor/ultra0.py を配置してから実行
bash Mac環境セットアップ.command
```

セットアップは`.venv`を作成し、Frida 16.5.9をインストールします。ADBはMuMu同梱版、PATH、Android SDKの順に探します。別のADBを使う場合は`ADB_PATH`にパスを指定してください。

## 使い方

MuMuのAndroidを起動し、PlayストアとGoogle Oneを開いてから順に実行します。

| ファイル | 操作 |
| --- | --- |
| `0_環境チェック.command` | Googleアプリ・ADB・Fridaなどを準備して確認 |
| `1_オファー一覧.command` | オファーの期間と価格を表示 |
| `2_決済画面を開く.command` | 12か月オファーの決済画面を開き、確定前で停止 |

Finderでダブルクリックするか、ターミナルから実行できます。

```bash
.venv/bin/python mac.py check
.venv/bin/python mac.py list
.venv/bin/python mac.py checkout
```

決済画面では、対象アカウント、プラン、無料期間、請求金額、更新日を確認してください。希望する条件と一致した場合だけ、端末で申込みを確定します。契約後はGoogle Playの「お支払いと定期購入」で契約内容と次回請求日を確認してください。

この補助ツールは、元ファイルのアカウント追加・カード登録・購入自動確定・期間加算の関数を呼びません。元ファイル自体はPythonコードとして読み込まれるため、信頼できるものだけを配置してください。

## 接続できない場合

MuMuのADBポートは再起動後に変わることがあります。26624〜26626を試しても接続できない場合は、MuMuに表示されるアドレスを指定します。複数端末がある場合も`--serial`を使います。

```bash
# アドレスは自分のMuMuの値に置き換えてください
.venv/bin/python mac.py check --serial 127.0.0.1:26625
```

Playストアがロゴ画面で止まる場合は、Android端末を再起動し、Googleアプリが単独で開くか確認してください。補助ツールはFridaを止めてGoogleアプリを先に起動し、その後Fridaを`--disable-preload`で開始します。他のFrida作業と同時には実行しないでください。

## 配布するもの・しないもの

配布するのは、自作のMac用補助ツール、起動ファイル、説明書、テストです。元コード、埋め込みAPK/DEX、認証情報、カード情報、オファートークン、実行ログ、端末画像は含みません。元ファイルの許諾は[出典・配布範囲](ATTRIBUTION.md)を確認してください。

補助ツールはトークンを出力・保存せず、元ファイルの標準出力も表示しません。ただし、元ファイルを実行する際は、そのコード自体の処理内容を確認してください。環境確認ではAndroid側のroot・Frida・課金モジュールを準備します。補助ツールは元ファイルのプロキシ解除関数を呼びません。
